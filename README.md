# Retail Sales Data Analysis (EDA)

An Exploratory Data Analysis (EDA) project focusing on understanding customer purchasing behavior, sales trends, and category performance.

## Key Findings & Executive Summary
1. **Gender Analysis:** Sales are evenly distributed between genders (Females 51% vs. Males 49%).
2. **Sales Trends:** May 2023 was the peak sales month ($56,450), while September 2023 was the lowest ($23,620).
3. **Product Performance:** Clothing is the best-selling category by volume with 939 units sold.
4. **Geographic Performance:** San Francisco is the top-revenue city ($71,335), whereas New York generated the lowest revenue ($34,390).
